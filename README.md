# Nova Arte Uniformes

Site da **Nova Arte Uniformes & Camiseteria** (Betim/MG): catálogo, páginas da casa e um **estúdio** em que o cliente monta a peça, vê a arte no tecido e pede orçamento no WhatsApp.

[ademiragencia/novaarteuniformes](https://github.com/ademiragencia/novaarteuniformes)

## O que tem

- Home, catálogo e ficha de produto
- Estúdio ao vivo (camiseta, polo, moletom — cor, texto, logo, frente/costas, técnica)
- Grade de tamanhos com mínimo de 10 peças
- Orçamento pronto no WhatsApp `(31) 97565-1420`
- Páginas Empresas, Técnicas, A casa e Contato

## Como rodar

```bash
npm install
npm run dev
```

O app sobe em `http://localhost:8080`.

```bash
npm run typecheck
npm run build
```

## Stack

React 19, TypeScript, Vite, TanStack Start, Tailwind v4.
